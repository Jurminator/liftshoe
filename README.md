# Liftshoe

Landing page for Liftshoe — a compact inflatable shoe set that lets smaller people see the acts at concerts.

- The website is the `site/` folder: plain HTML and CSS, no build step.
- `npm run check` verifies the page; `npm run check:release` is the gate before going live.
- Spec: `docs/specs/` · Facts the page may state: `docs/approved-facts.md` · Agent guide: `CLAUDE.md`
